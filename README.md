# Port Terminal Manager v2

A live port simulation with 4 docking lines, priority-based queuing, and a clean Engine ↔ UI split. Pure JavaScript (ES2020+), ES modules only, zero runtime dependencies.

---

## How to Run

### Prerequisites

- **Node.js v18+** (v20 recommended) — for tests and the local dev server
- A modern browser (Chrome, Edge, Firefox) — for the UI

### 1. Run the test suite

```bash
node --test tests/
